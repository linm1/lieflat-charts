# 彩色換膚樣張

**這裡只查配色，不查結構。**

渲染程式碼、幾何、動畫的正本永遠是 `templates/` 根目錄那四個 gallery。彩色樣張是它們的換膚版——逐節點對應同一份資料和動效，從這裡照抄結構等於繞遠路，而且容易漂。

內建預設的色值正本是 `color-presets.js`。樣張 header 裡那些散落的說明（加墨係數、色盤順序）只是自述，規則本體在 `SKILL.md` 第六點五節。Agent 可以根據資料結構和使用場景自動選擇一套預設，不要求使用者先觸發彩色。同一份 HTML 或同一組交付只能使用一種色彩系統，禁止跨預設混用；使用者拿到成品後可以繼續調色，但要重新檢查對比度、視覺主次和資料語義。

## Custom 不是第四套內建預設

使用者明確提供品牌色、hex 或完整色盤時，可以按 `SKILL.md` 的角色規則建立一套交付內 `CUSTOM`。它不出現在這裡，因為不存在一套對所有使用者都成立的 custom 樣張。Custom 不得從三套內建預設借色補齊，也不得回寫 `color-presets.js`，除非使用者明確要求把品牌色固化為專案級預設。

Treemap 的四種實作已經加入 Basics gallery：Mono 靠父級標題帶和留白分組；Porcelain 用明度對應有序父組；Palm 用色相對應頂層類目；Wire 只給一個葉子使用螢光橙。

## 三套

| 檔案 | 色系 | 色彩邏輯 | 適用 |
| - | - | - | - |
| `*-porcelain.html` | 青瓷藍 | 單色相明度階 | 有序資料、單序列 |
| `*-palm.html` | 椰林綠 | 色相 = 類目 | 無序類目 ≤4（5–6 勉強） |
| `*-wire.html` | 編輯部紅 | 灰階 + 一個螢光橙 | 幾乎所有場合，要一個視線落點 |

每套四個 gallery（basics / glance / lupi / maps），共 12 個，沒有缺口。地圖樣張只在使用者明確要求地圖時才用得上。

archive（陶土青灰）已歸檔，不再是候選。它和 palm 都是"色相=類目"，功能重疊。

## 三個互動大圖

`big-circular` / `big-force` / `big-threads` 只有 porcelain 和 palm 兩套，沒有 wire。

原因：wire 本身就是黑灰階加一個螢光橙，和原版 mono 大圖的差別只在強調色，做出來近乎重複。要 wire 風格的大圖，直接用 `templates/` 根目錄的原版。

這三張是**暗底圖**，色彩邏輯和淺卡不同：卡底壓深，8 檔單色相階從亮到暗，編碼的是"離核心多遠"（亮 = 核心），不是類目。色值在 `color-presets.js` 各套的 `DARK` 塊裡。

為什麼不用色相分類目：這三張分別需要 5 / 8 / 三列結構的檔位，超過 palm 綠黃區間的容量上限（≤6）。按 SKILL.md 門一的規則，只能走單色相明度階。

`big-threads` 的 hover 強調是改 opacity（線恆為 `DK8[0]`），不用 `DARK.HL`。
